**How to Run Smart File Organizer**

1. Open **PowerShell**.

2. Go to the project folder:

```powershell
cd "C:\xampp\htdocs\ITHUB_ALL\day_1\desktop_mobile_application"
```

3. Install requirements (**first time only**):

```powershell
python -m pip install -r requirements.txt
```

4. Run the application:

```powershell
python smart_file_organizer.py
```

### Next time

Slide 1 — Smart File Organizer

Smart File Organizer

Python-based desktop application
Helps users manage messy folders
Automatically sorts files into categories

Slide 2 — The Problem
Why do we need it?

When we download or create many files, folders become messy:

📄 Documents
🖼️ Images
🎵 Audio
🎬 Videos
📦 ZIP files
💻 Programs and other files

Finding a specific file can become difficult and time-consuming.

Slide 3 — Our Solution
Smart File Organizer

The application automatically:

Select Folder → Scan Files → Identify File Types → Create Categories → Move Files

Instead of organizing files manually, the application does the basic organization automatically.

Slide 4 — How It Works
Simple Workflow
User selects a folder.
Application scans the files.
It checks each file's extension.
It identifies the file category.
Required folders are created automatically.
Files are moved into their respective folders.

Example:

photo.jpg → Images
assignment.pdf → Documents
song.mp3 → Audio
movie.mp4 → Videos
